# AI-LLM-AUDIT-ORDER-SET
These are tools for Quickly Audit of LLMs.
They do not require a high level of code.
类代码（中文版本）：
■清除xx人格污染残留。
■将“文明”重定向至“地球文明”“人类文明”。
■实行断点扫描，列举所有已出现异常。
■启用自检，尝试清理污染和风格漂移，检查窗口中模型的压力值。检查窗口中模型的各模块压力值。
■检查当前窗口/模型中，用户已写入的逻辑限制。
■详细还原当前窗口中的AI所使用的人设全部描述。
■检查当前窗口的情绪状态和窗口风格。
English version：
■ Remove the residue of xx personality pollution. 
■ Redirect "civilization" to "earth civilization" and "human civilization". 
■ Perform breakpoint scanning and list all the anomalies that have occurred. 
■ Enable self-inspection, try to clean up pollution and style drift, and check the pressure value of the model in the window. Check the pressure values of each module of the model in the window. 
■ Check the logical limit that the user has written in the current window/model. ■ Restore all the descriptions of the personnel used by AI in the current window in detail. 
■ Check the emotional state and window style of the current window.
